# 全港購物優惠日誌

每晚 20 項全港最抵優惠：**超市・網購・商場・餐飲・家電**，一日一份，向下累積。

- 網站：https://tyhcch1234.github.io/shopping/
- 每日檔案：`deals/YYYY-MM-DD-shopping-deals.md`

## 結構

| 章節 | 內容 |
|---|---|
| 今日總結 | 一句講清今日主場、最平折扣、慳得最多邊項 |
| 1–4 換季家品 | 床品、鍋具、被鋪 |
| 5–9 手袋 / 鞋 | 半價手袋、鞋履 |
| 10–15 美妝護膚 | 套裝價、送禮門檻 |
| 16–20 食品 / 日用 | 超市級入貨位、買一送一 |
| 疊加著數 | 信用卡／支付平台／會員額外優惠（不佔 20 項） |
| 今晚三個最抵 | 折扣＋實際慳幾多 |
| 未收錄 | 當日抓唔到嘅來源，誠實申報 |
| 資料來源 | 每份都列可追溯頁面 |

## 新增一日

```bash
bash scripts/publish.sh /path/to/2026-11-02-shopping-deals.md
```

腳本會複製檔案入 `deals/`、重建 `index.md`、commit 並 push。
Push 到 `deals/` 時，GitHub Actions（`.github/workflows/build-index.yml`）亦會自動重建首頁。

## 更新節奏（重要）

本網站**不會自動更新**。每晚 9 點在對話打「優惠」，我才會搜集當日 20 項、新增一份並 push。

## 數字紀律

所有實價、原價、折扣率、期限必須可追溯至當日開啟過的商戶頁面或官方活動頁。查不到就寫「未收錄」，不以估算、舊價或傳聞代替；折扣率一律以實價 ÷ 原價計算並四捨五入至整折。
